# Piloto WhatsApp Web — somente leitura
1. Abra `chrome://extensions` ou `edge://extensions`.
2. Ative Modo do desenvolvedor.
3. Clique em Carregar sem compactação.
4. Selecione esta pasta.
5. Mantenha WhatsApp Web e Secretária IA abertos.

A extensão não envia mensagens e não clica em chats. Ela captura somente mensagens recebidas que o WhatsApp Web renderiza na conversa visível. É uma ponte temporária de validação, não a integração oficial.
